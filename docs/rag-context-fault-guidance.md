# UPS 故障更换物品知识

## 故障场景

数据中心一号楼二层 2 号 UPS 出现以下问题：

- UPS 高温报警；
- UPS 风扇报警，设备散热能力下降；
- 直流侧电压异常；
- 巡检确认部分电容鼓包或容量衰减。

该故障可能同时涉及散热部件和储能部件，不能只生成一个“UPS 配件”采购项。

## 需要采购的物品

在现场确认对应部件确实损坏并需要更换后，生成以下独立采购项：

| 故障部位 | 采购物品 | 数量 | 单位 | 备注 |
| --- | --- | --- | --- | --- |
| UPS 散热系统 | UPS 风扇 | 按现场确认数量 | 个 | 风扇本体故障或无法正常运行时更换 |
| UPS 直流储能部分 | UPS 电容 | 按现场确认数量 | 个 | 电容鼓包、漏液或检测确认容量衰减时更换 |

## 数量示例

如果现场确认：

- 2 个 UPS 风扇损坏；
- 4 个 UPS 电容需要更换；

则采购需求应为：

```text
UPS 风扇：2 个
UPS 电容：4 个
```

这两个物品属于同一次故障，可以放在同一张采购草稿中，但必须保存为两个独立采购项。

## 不应采购或推断的内容

以下信息不能仅根据本故障描述自动生成：

- 品牌；
- 型号；
- 电容容量和耐压；
- 风扇尺寸和接口；
- 兼容型号；
- 采购数量。

品牌、型号和规格需要根据 UPS 资产信息、现场铭牌或产品目录进一步确认。数量必须以用户或现场人员明确确认的信息为准。

## 其他故障对应关系

| 故障现象 | 可能涉及的采购物品 |
| --- | --- |
| UPS 风扇报警且风扇停转 | UPS 风扇 |
| UPS 电容鼓包或检测失效 | UPS 电容 |
| UPS 控制板故障 | UPS 控制板 |
| UPS 逆变模块故障 | UPS 逆变模块 |
| UPS 整流模块故障 | UPS 整流模块 |

只有现场确认某个部件需要更换时，才将该部件加入采购需求。多个部件同时确认时，生成多个采购项。
