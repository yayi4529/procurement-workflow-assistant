# 飞书卡片与 Agent 交互设计

本文件定义四角色卡片、自然语言辅助和“问智能助手”交互。

完整规范见 `CODEX_PROJECT_SPEC.md` 第 8 至 13 节。

## 1. 统一原则

- 正式字段写入由卡片触发；
- Agent 只生成查询条件和候选预填；
- 后端返回正式值后刷新卡片；
- Agent 一次追问一个后端缺失字段；
- 推荐最多 3 项；
- 正式提交必须由用户点击卡片按钮。

## 2. 问智能助手

点击卡片按钮后：

```text
写入 Agent 会话上下文
→ 机器人发送当前咨询提示
→ 用户在同一私聊窗口继续提问
```

Agent 可返回：

- 文字解释；
- 查询结果；
- 预填建议卡片。

## 3. 需求人

```text
自然语言快速创建
或
直接打开卡片
→ 保存草稿
→ 字段完整
→ 确认提交审批
→ 推送楼长
```

## 4. 楼长

```text
收到待审核卡片
→ 填写审核信息
→ 提交采购员
```

也可以：

```text
驳回
供应商拉黑确认
查询历史采购
问智能助手
```

## 5. 采购员

```text
收到待采购卡片
→ 查询或预填供应商资料
→ 保存实际采购信息
→ 提交仓库
```

## 6. 仓库管理员

```text
收到待入库卡片
→ 填写库位、数量和备注
→ 确认入库
```
